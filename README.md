鸢尾花数据集简介
鸢尾花数据集（Iris Dataset）是机器学习中最经典的入门数据集之一：

样本数：150 个
特征数：4 个（花萼长度、花萼宽度、花瓣长度、花瓣宽度）
类别数：3 类（Setosa(山鸢尾)、Versicolor(变色鸢尾)、Virginica(维吉尼亚鸢尾)）
特点：Setosa 类与其他两类线性可分，后两类略有重叠


支持向量机（Support Vector Machine, SVM） 是一种监督学习算法，主要用于分类和回归任务。在分类任务中，它的目标是找到一个最优超平面（在二维中是一条直线），将不同类别的数据点尽可能清晰地分开。
一句话概括：找到一个最优的分类边界（超平面），使得两类样本之间的间隔最大化。

核心思想：
最大间隔分类器：SVM 不仅要正确分类数据，还要使得分类边界（超平面）到最近的数据点（称为支持向量）的距离最大。
支持向量：离分类边界最近的那些点，它们决定了分类边界的位置。
核技巧（Kernel Trick）：当数据线性不可分时，SVM 可以通过核函数将数据映射到高维空间，使其在高维空间中线性可分。

SVM 算法特点：
鲁棒性强：对异常值和噪声有一定容忍度；
小样本表现好：在样本量不大时仍能取得高准确率；
理论清晰、可解释性强：其“最大间隔”思想直观且数学基础扎实
